## How to import a workflow

1. Open the workflow folder and download `workflow.json`.
2. In n8n, create a new workflow.
3. Click the **⋯** menu (top right) → **Import from File**, and pick `workflow.json`.
   (Or copy the JSON and paste it straight onto the canvas with Ctrl+V.)
4. Add your own credentials (e.g. OpenAI API key) to the nodes that need them.

## Need n8n?

- **n8n Cloud:** free trial at n8n.io
- **Self-host for free:** install Node.js, then run `npx n8n` and open http://localhost:5678
